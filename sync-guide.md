# 🔄 Синхронизация данных между ПК

## 📋 Варианты синхронизации

### 1️⃣ **Внешняя база данных (Лучший вариант)**

#### Настройка сервера БД (на одном ПК):

1. Запустите только PostgreSQL:
```bash
docker-compose up -d postgres
```

2. Настройте PostgreSQL для внешних подключений:
```bash
# Войти в контейнер
docker-compose exec postgres bash

# Отредактировать postgresql.conf
echo "listen_addresses = '*'" >> /var/lib/postgresql/data/postgresql.conf

# Отредактировать pg_hba.conf
echo "host all all 0.0.0.0/0 md5" >> /var/lib/postgresql/data/pg_hba.conf

# Перезапустить
exit
docker-compose restart postgres
```

3. Узнайте IP адрес сервера:
```bash
ipconfig
# Найдите IPv4 адрес (например: 192.168.1.100)
```

#### На других ПК:

1. Используйте `docker-compose.shared-db.yml`:
```bash
# Отредактируйте IP адрес в файле
# SPRING_DATASOURCE_URL: jdbc:postgresql://192.168.1.100:5432/talimcrm_db

# Запустите
docker-compose -f docker-compose.shared-db.yml up -d
```

**Плюсы:**
- ✅ Данные всегда синхронизированы
- ✅ Работает в реальном времени
- ✅ Не нужно копировать файлы

**Минусы:**
- ❌ Нужен один ПК постоянно включенным
- ❌ Требуется сетевое подключение

---

### 2️⃣ **Резервное копирование (Простой вариант)**

#### Создание бэкапа:

```bash
# На ПК 1
backup.bat

# Файл сохранится в папку backups/
# Например: backups/talimcrm_backup_20250930-223000.sql
```

#### Перенос на другой ПК:

1. Скопируйте файл бэкапа на другой ПК
2. Положите в папку `backups/`
3. Запустите:
```bash
restore.bat
```

**Плюсы:**
- ✅ Простота
- ✅ Не требует сети
- ✅ Полный контроль

**Минусы:**
- ❌ Ручная синхронизация
- ❌ Данные не в реальном времени

---

### 3️⃣ **Облачное хранилище (Автоматический вариант)**

#### Настройка автоматических бэкапов в облако:

1. Установите облачный клиент (Google Drive, Dropbox, OneDrive)

2. Создайте скрипт автоматического бэкапа:

**auto-backup.bat:**
```batch
@echo off
:: Создать бэкап
call backup.bat

:: Скопировать в облако (измените путь)
copy backups\*.sql "C:\Users\YourName\Google Drive\TalimCRM-Backups\"

echo Backup uploaded to cloud!
```

3. Добавьте в планировщик задач Windows:
   - Откройте "Планировщик заданий"
   - Создайте задачу: запускать `auto-backup.bat` каждый день

4. На других ПК:
   - Скопируйте последний бэкап из облака
   - Запустите `restore.bat`

**Плюсы:**
- ✅ Автоматические бэкапы
- ✅ Доступ из любого места
- ✅ История изменений

**Минусы:**
- ❌ Требует облачное хранилище
- ❌ Не в реальном времени

---

### 4️⃣ **Docker Volume синхронизация**

#### Экспорт volume:

```bash
# На ПК 1: Создать архив volume
docker run --rm -v talimcrm-v1_postgres_data:/data -v %cd%:/backup alpine tar czf /backup/postgres_data.tar.gz -C /data .
```

#### Импорт на другом ПК:

```bash
# На ПК 2: Создать volume
docker volume create talimcrm-v1_postgres_data

# Восстановить данные
docker run --rm -v talimcrm-v1_postgres_data:/data -v %cd%:/backup alpine tar xzf /backup/postgres_data.tar.gz -C /data
```

**Плюсы:**
- ✅ Полная копия всех данных
- ✅ Включая настройки PostgreSQL

**Минусы:**
- ❌ Сложнее для новичков
- ❌ Большие файлы

## 🎯 Рекомендации

### Для домашнего использования:
**Вариант 2** (Резервное копирование) - самый простой

### Для офиса/команды:
**Вариант 1** (Внешняя БД) - самый удобный

### Для распределенной работы:
**Вариант 3** (Облако) - автоматизация

## 📝 Пример workflow

### Ежедневная работа:

**Утром (на рабочем ПК):**
```bash
# Восстановить последний бэкап
restore.bat
```

**Вечером (перед уходом):**
```bash
# Создать бэкап
backup.bat

# Скопировать в облако/флешку
```

**На другом ПК:**
```bash
# Скопировать бэкап
# Восстановить
restore.bat
```

## 🔐 Безопасность

### Для production:

1. **Измените пароли** в `docker-compose.yml`
2. **Шифруйте бэкапы:**
```bash
# Зашифровать
7z a -p backup_encrypted.7z backups/*.sql

# Расшифровать
7z x backup_encrypted.7z
```

3. **Используйте VPN** для внешних подключений к БД
